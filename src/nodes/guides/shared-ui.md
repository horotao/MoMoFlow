# Image 节点与工具栏

将本地图片文件拖入画布即可导入。图片按原比例显示，悬停或单选时可在共用工具栏里替换图片、下载原图或查看大图。Tools、标记、添加到素材库、发送和评论暂为预留入口。替换保留图片的位置、输出端口和连线。导入图片只展示素材，可以拖动、框选、撤销和恢复。

从空白画布右键选择「图片」会创建 384 × 384 的 Image 节点。节点和工具栏使用 [ImagePromptNode](../../components/image-prompt-node/ImagePromptNode.tsx) 及同目录的字体、图标与动效。[CanvasImageNode](../CanvasImageNode.tsx) 将标题拖动、锁定、提示词、数量、模型选择、比例、历史结果和端口接入画布。工具栏固定为屏幕像素尺寸；选中节点时缩小画布仍可操作。缩放显示为 14% 及以下时收起仅由悬停触发的工具栏。模型选择和比例弹层使用屏幕坐标。节点状态随工作流保存。

工具栏和「生成选项」共用画面比例。新节点默认「自动」，空节点依据按输入端口排序的第一张可用参考图调整外框，无可用图时为正方形。选择固定比例时按所选比例调整。短边为 384，顶部中心固定。已有结果时，外框按当前结果的实际尺寸比例显示，切换历史也会更新外框。修改画面比例用于下一次生成。小地图按节点外框的比例绘制。

悬停、选中或聚焦 Image 节点时，连入的参考图以缩略图显示。首次生成前，缩略图位于底部按钮上方；生成中和已有结果的紧凑编辑框将缩略图放在提示词上方，DOM 顺序与视觉顺序一致。紧凑编辑框中的发送按钮保留 36px 箭头、40px 外圈及数量展开，外圈补有与 FLORA 一致的双层阴影。缩略图行和按钮一起淡入上移、淡出下移。参考缩略图按 FLORA 的输入预览样式呈现：40 × 40px、12px 圆角、1px 的 `#fafaf223` 边框，缩略图间距 4px，上方预留 6px。悬停或键盘聚焦时，图片缩至 80%，卡片横向展开，显示最多 80px 宽的文件名和「Image」两行文字；字体为 Geist Sans 12px / 13.5px，文字颜色分别为 `#eeeeec` 和 `#b5b3ad`。卡片背景为 `#191918e6`，右内边距 8px，14px 的移除按钮位于左上角外移 6px。展开、收起与图片缩放为 250ms 的 `cubic-bezier(0, 0, .2, 1)`，边框与移除按钮淡入淡出为 150ms；连续反向操作从当前状态继续，键盘及减少动态效果设置下即时切换。上游尚未出图时显示占位，出图、切换历史或替换素材后同步更新。移除只断开该缩略图对应的连线，可通过画布撤销恢复。目标节点锁定时可查看参考图。两张及以上参考图使用 dnd kit 拖拽排序：拖动的卡片直接跟随指针，邻图以 200ms 过渡让位，松手提交顺序；画布缩放下保持指针位移一致，横向溢出时可向边缘拖动自动滚动。可用空格或回车开始排序、方向键移动、空格或回车确认、Escape 取消；键盘及减少动态效果下即时落位。移除按钮不触发排序，排序不拖动或平移画布。

Image 节点与导入图片的标题使用 12px 屏幕字号，标题行宽度随节点缩放。空间不足时先截断节点名，再截断模型名，悬停文字可查看全名。缩放显示为 8%–14% 时只保留节点类型图标，7% 及以下隐藏标题内容。空节点在极远总览中可从卡片上沿拖动。

Image 的进度动画按 25 秒预计用时计算。等待任务开始时显示准备态，开始后连续填充至 95%，收到结果后补满并淡入图片。边框扫光随节点尺寸调整，覆盖整个旋转周期。开启减少动态效果时显示静态阶段进度。

首次生成和重新生成均保留当前选择，进度层占据图片区域。从右侧「+」创建的下游 Image 在生成期间保持与上游相连。选中或悬停节点可见顶部工具栏及底部提示词面板，悬停或聚焦面板时其内容提高到完整不透明度。框选期间及选中多个节点时隐藏所有顶部工具栏。选择工具下，悬停显示工具栏的 Image 临时叠在其他节点上方，移出后恢复正常层级。

单选 Image 时，右侧由 [ImageInspector](../../components/image-prompt-node/ImageInspector.tsx) 展示 320px 宽的侧栏。有图片时，图片信息在上、生成选项在下；导入图仅显示图片信息。信息包含名称、格式、文件大小、分辨率和创建时间，生成图额外显示该图片生成记录中的模型名称，不展示创建者。新导入及新生成的素材记录创建时间；旧素材仅在已有记录可确定时显示日期，缺失值显示「—」。信息读取不修改节点数据与撤销记录。名称右侧的信息按钮仅收起详情，保留底部工具栏。五个工具图标为预留；更多菜单复用 FLORA 图标与布局，提供全屏（F）及预留的保存到素材库入口。

未生图的 Image 仍显示图片信息卡片：名称默认为「Image」，保留信息按钮与底部工具图标，不渲染元信息行；没有素材时信息按钮、更多操作和全屏快捷键不可用。空态与有图状态的侧栏位置一致，生成选项始终在卡片下方。

图片信息的标题为 14px；详情采用 12px 字号、16px 行高容器和 8px 行间距，标签与数值分别使用 12px / 13.5px 文字行高。详情底部保留 8px 留白，左右内边距 12px，与 FLORA 保持一致。

「生成选项」标题可以折叠；侧栏操作不拖动或缩放画布，锁定后禁用参数编辑，仍可查看图片信息与预览。参数修改进入画布撤销记录并随项目保存；多选或取消选择时隐藏侧栏。下拉菜单在画布面板上方使用屏幕坐标，并支持方向键、Enter 和 Escape。

生成选项中的二级菜单使用 Radix Select：菜单按内容自适应宽度、最大高度 320px，12px 圆角与 16px 背景模糊；选项高 40px，使用 8px 圆角和 12px 水平内边距。工具栏比例菜单同样最多 320px；两处均受视口可用高度限制，超出内容通过细滚动条访问，滚动不影响画布。方向键及 Home / End 可移动焦点并滚动到对应选项，Enter 确认、Escape 关闭并回到触发按钮。悬停高亮独立于选中勾选，点击确认后收起。指针打开和关闭分别采用 150ms / 80ms 的 0.97 缩放淡入淡出；键盘操作及减少动态效果设置下即时切换。

出图后可从结果图片区域拖动整个节点。主画布通过 `canvasImageDrag` 统一拦截结果图（含淡入淡出层）和历史缩略图的浏览器原生拖拽；保留提示词编辑、历史切换、端口连线与锁定行为。
