# Image 节点与工具栏

将本地图片文件拖入画布，或复制图片后在画布按 Cmd/Ctrl + V，即可导入。粘贴的图片放在鼠标所在画布位置，鼠标未指向画布时放在视野中央。图片按原比例显示，悬停或单选时可在共用工具栏里替换图片、下载图片、查看大图或设置颜色标记。导入图与生成图共用「工具」菜单，按顺序显示「裁剪」「放大图片」「移除背景」「局部重绘」「扩图」，均使用对应的 Flora 图标。裁剪与局部重绘可用，放大、移除背景和扩图为禁用入口。添加到素材库、发送和评论暂为预留入口。替换保留图片的位置、输出端口和连线。

画布上的导入图和生成结果用灰色棋盘格显示透明区域。半透明像素仍能透出格纹，不透明像素完全覆盖格纹。棋盘格只作为节点中的预览背景，下载和连线使用原始素材。

「工具」菜单按 Flora 实测使用 30% 不透明度的黑色底色。菜单面板及外侧定位层各使用 16px 背景模糊与 16px 圆角，模糊保持屏幕像素尺寸，让覆盖区域下方的图像颜色透出。

## 图片裁剪

生成图与导入图共用 [ImageCropEditor](../../components/image-prompt-node/ImageCropEditor.tsx)，从「工具 → 裁剪」或图片信息栏的裁剪按钮进入。按 Flora 实操：在当前节点展开完整原图，保持顶部中心锚点；其他节点的内容与连线保留 40% 亮度，名称、模型标签、标题色标和画布网格保持原亮度，框外原图显示黑色遮罩。工具栏显示「裁剪」，四角与四边中点提供白色手柄；拖动边角调整范围，框内拖动移动裁剪框。手柄、描边保持屏幕尺寸，拖动不添加缓动，不拖动节点或平移画布。Enter 或普通左键外部点击应用，Escape 放弃本次调整；中键拖动或按住空格拖动由画布处理平移，支持从空白处、原图和裁剪手柄开始，保留当前未确认的裁剪范围，松开后可继续裁剪；退出后焦点回到当前节点「工具」，保证画布撤销可直接使用。「工具」菜单使用 Radix，支持方向键、Enter、Escape 与焦点恢复；裁剪手柄支持方向键逐像素调整，Shift 为 10 像素。

裁剪在浏览器内生成 PNG，不调用模型。只替换当前历史项的图片内容，保留该项 ID、生成来源、提示词和其他历史；以新内容哈希使下游识别变化。输出端口、参考图、下载、全屏和小地图同步使用裁剪结果。`FileAsset.crop` 保存原图素材与原图像素矩形，重新进入时恢复完整原图及已保存的框，可向外展开还原；框到达完整原图时恢复原始文件。原图与裁剪图都纳入 Blob 引用和 IndexedDB 保存恢复，确认一次独立撤销，取消和拖动过程不写入图数据。锁定、空态和生成中禁用裁剪；加载或转换失败保留素材并允许重试。减少动态效果保留直接拖动，不附加装饰动效。

## 局部重绘

生成图与导入图可从「工具 → 局部重绘」打开 [ImageInpaintEditor](../../components/image-prompt-node/ImageInpaintEditor.tsx)。完整显示当前图片并保持顶部中心锚点；其他节点和连线复用裁剪的压暗规则，画布网格保持原亮度。右上角状态沿用节点模型标签的单行截断和缩放规则。工具栏和右侧「生成选项」均可单选 GPT Image 2.6 Sunburst 或 Flare，默认 Sunburst。重绘固定使用 OpenAI 官方渠道，生成选项省略渠道商。右侧按图片信息、生成选项、画笔选项的顺序排列，内容超出时整列可用滚轮滚动，滚动条隐藏。上方或下方还有可滚动内容时，对应边缘显示 56px 渐隐，滚到该边缘后取消渐隐。笔刷直径默认 50 个画布像素，滑杆可在 5–100 px 之间调整，方向键每次调整 1 px。加号和减号切换添加或擦除选区，光标同步显示当前笔刷大小和模式。「清除」清空选区，Ctrl／Cmd+Z 可撤销最近一笔或上次清除。

光标的白色描边保持 2 个屏幕像素，白色填充不透明度为 25%。所画区域以 85% 不透明度的 `#6cb37c` 和交错的加号网格预览，颜色根据参考截图与未涂原图的像素差估算。支持拖动涂抹、方向键移动、Enter 点涂、Shift 加方向键连续画，以及空格或中键平移。预览和导出的蒙版按同一顺序应用添加与擦除的笔迹。

提示词胶囊沿用 Flora 实测的内间距、12px 字号和半透明底色。输入时显示光标，Shift+Enter 换行，空提示词可用 Tab 接受扫光示例。Escape 或外部点击取消。有蒙版和提示词时可展开共用的发送按钮，选择生成 1–20 张，默认 1 张。发送后在右侧空位创建一个「局部重绘」Image，并连线标出来源，自动按所选数量加入原有任务队列。新节点保存本次重绘选用的模型和参数，以及原图和蒙版；重新选择、裁剪或删除来源图，都不会把已保存的笔迹套到另一张图上。浏览器将选区编码为与输入 PNG 尺寸相同的 Alpha 蒙版，涂抹处透明；实际编辑由模型根据遮罩和提示词生成。新节点支持修改重绘提示词、模型和生成参数，也可再次生成、查看历史及连接下游。重绘参数独立于来源节点和普通 Image 的生成偏好。节点与来源连线在同一步创建，图片和蒙版随项目保存。任务失败时可在队列重试，未提交的草稿不会写入画布。

## Image 节点

从空白画布右键选择「图片」会创建 384 × 384 的 Image 节点。节点和工具栏使用 [ImagePromptNode](../../components/image-prompt-node/ImagePromptNode.tsx) 及同目录的字体、图标与动效。[CanvasImageNode](../CanvasImageNode.tsx) 将标题拖动、锁定、提示词、数量、模型选择、比例、历史结果和端口接入画布。工具栏固定为屏幕像素尺寸；选中节点时缩小画布仍可操作。缩放显示为 14% 及以下时收起仅由悬停触发的工具栏。模型选择和比例弹层使用屏幕坐标。节点状态随工作流保存。

Image、导入图片与 Text 顶部工具栏，以及框选和群组工具栏共用 [NodeToolbarTooltip](../../components/NodeToolbarTooltip.tsx)。首次悬停约 300ms 后显示提示，已打开提示后 300ms 内移到相邻按钮跳过等待；短暂停留后移出会取消显示。提示位于按钮上方，间隔 4px，以屏幕像素定位并自动避让视口边缘；禁用入口也可查看说明，但仍不可操作。点击、移出或 Escape 收起提示，键盘聚焦即时显示；颜色标记及模型菜单沿用原有键盘行为。样式采用 Flora 的 12px 圆角、半透明底、16px 模糊和 12px 字体，入场 150ms／退场 80ms，从 0.98 缩放淡入；键盘和减少动态效果时即时切换。不使用浏览器原生 title，避免重复提示。[主画布验收记录](../../../docs/screenshots/node-toolbar-tooltips/README.md)。

工具栏和「生成选项」共用画面比例。普通新节点从上次生成偏好创建，无偏好时为 1:1；空节点按所选比例调整外框。连接首个参考输入或从图片拖线创建下游 Image 时，按输入端口顺序取第一张可用参考图，将其宽高比匹配到当前模型和渠道最接近的受支持比例，同步更新外框、工具栏、生成选项及 API 尺寸。自动匹配不覆盖浏览器记住的生成偏好。旧节点保留的「自动」在参考图可用后也会同步为具体比例。短边为 384，顶部中心固定。已有结果时，外框按当前结果的实际尺寸比例显示，切换历史也会更新外框。修改画面比例用于下一次生成；开始等待或生成后，外框立即按该任务实际提交的比例显示。切回旧历史时按该图片的实际尺寸显示；取消或失败后恢复已有结果的尺寸，成功后按新结果的实际尺寸显示。小地图按节点外框的比例绘制。

自动跟随参考图的状态随节点保存，覆盖上游稍后出图、图片替换、历史切换及参考图排序；锁定时不修改参数。用户手动选择比例后停止自动跟随，之后新增非首个输入不覆盖手动比例。参考图尺寸尚不可用时保留当前比例，待图片加载后同步。

悬停、选中或聚焦 Image 节点时，连入的参考图以缩略图显示。首次生成前，缩略图位于底部按钮上方；生成中和已有结果的紧凑编辑框将缩略图放在提示词上方，DOM 顺序与视觉顺序一致。紧凑编辑框中的发送按钮保留 36px 箭头、40px 外圈及数量展开，外圈补有与 FLORA 一致的双层阴影。缩略图行和按钮一起淡入上移、淡出下移。参考缩略图按 FLORA 的输入预览样式呈现：40 × 40px、12px 圆角、1px 的 `#fafaf223` 边框，缩略图间距 4px，上方预留 6px。悬停或键盘聚焦时，图片缩至 80%，卡片横向展开，显示最多 80px 宽的文件名和「Image」两行文字；字体为 Geist Sans 12px / 13.5px，文字颜色分别为 `#eeeeec` 和 `#b5b3ad`。卡片背景为 `#191918e6`，右内边距 8px，14px 的移除按钮位于左上角外移 6px。展开、收起与图片缩放为 250ms 的 `cubic-bezier(0, 0, .2, 1)`，边框与移除按钮淡入淡出为 150ms；连续反向操作从当前状态继续，键盘及减少动态效果设置下即时切换。上游尚未出图时显示占位，出图、切换历史或替换素材后同步更新。移除只断开该缩略图对应的连线，可通过画布撤销恢复。目标节点锁定时可查看参考图。两张及以上参考图使用 dnd kit 拖拽排序：拖动的卡片直接跟随指针，邻图以 200ms 过渡让位，松手提交顺序；画布缩放下保持指针位移一致，横向溢出时可向边缘拖动自动滚动。可用空格或回车开始排序、方向键移动、空格或回车确认、Escape 取消；键盘及减少动态效果下即时落位。移除按钮不触发排序，排序不拖动或平移画布。

Image 节点与导入图片的标题使用 12px 屏幕字号，标题行宽度随节点缩放。空间不足时先截断节点名，再截断模型名，悬停文字可查看全名。缩放显示为 8%–14% 时只保留节点类型图标，7% 及以下隐藏标题内容。空节点在极远总览中可从卡片上沿拖动。

Image、导入图片与 Text 共用 [ImageNodeTitle](../../components/image-prompt-node/ImageNodeTitle.tsx)。选中且未锁定时，名称悬停显示浅灰圆角底色，双击原位编辑并全选；也可聚焦名称后按 Enter 或 F2。输入框随文字宽度变化，保持屏幕字号与白色内描边。Enter 或失焦保存，Escape 取消，空白名称保留原名；输入法确认不提前提交。一次改名独立撤销，名称随项目保存恢复。编辑名称不拖动节点、不触发画布缩放或快捷键。未选中和锁定时保留标题拖动规则；导入图的自定义名称在替换素材后保留，素材文件名仍使用原始记录。

Image 的进度动画默认按 25 秒估算；Grok Imagine 2.0 和 Kling V4 Image 分别按 15 秒和 60 秒估算，菜单和节点共用对应的参考时长。等待任务开始时显示准备态，开始后连续填充至 95%，收到结果后补满并淡入图片。边框扫光随节点尺寸调整，覆盖整个旋转周期。开启减少动态效果时显示静态阶段进度。

首次生成和重新生成均保留当前选择，进度层占据图片区域。从右侧「+」创建的下游 Image 在生成期间保持与上游相连。选中或悬停节点可见顶部工具栏；已有结果时，底部提示词面板默认隐藏，仅悬停图片区域时显示，聚焦面板内控件期间保持显示，选中节点或连接 Text 提示词不会让面板常显。悬停或聚焦面板时其内容提高到完整不透明度。框选期间及选中多个节点时隐藏单节点顶部工具栏；松手后在多个所选节点上方显示[多选工具栏](../../../README.md#画布框选)。选择工具下，悬停显示工具栏的 Image 临时叠在其他节点上方，移出后恢复正常层级。

单选 Image 时，右侧由 [ImageInspector](../../components/image-prompt-node/ImageInspector.tsx) 展示 320px 宽的侧栏。有图片时，图片信息在上、生成选项在下；导入图仅显示图片信息。信息包含名称、格式、文件大小、分辨率和创建时间，生成图额外显示该图片生成记录中的模型名称，不展示创建者。新导入及新生成的素材记录创建时间；旧素材仅在已有记录可确定时显示日期，缺失值显示「—」。信息读取不修改节点数据与撤销记录。名称右侧的信息按钮仅收起详情，保留底部工具栏。五个工具图标为预留；更多菜单复用 FLORA 图标与布局，提供全屏（F）及预留的保存到素材库入口。

未生图的 Image 仍显示图片信息卡片：名称默认为「Image」，保留信息按钮与底部工具图标，不渲染元信息行；没有素材时信息按钮、更多操作和全屏快捷键不可用。空态与有图状态的侧栏位置一致，生成选项始终在卡片下方。

双击生成结果或导入图片可打开 [ImageAssetPreview](../../components/image-prompt-node/ImageAssetPreview.tsx) 全屏预览；导入工具栏的查看大图、图片信息菜单的全屏及 F 快捷键共用该界面。双击在捕获阶段拦截，锁定图片也能查看，不触发画布双击缩放。空节点不打开预览。

全屏复用 Flora 的 Single／Masonry 两种布局、历史缩略图、前后切换、图片信息和原始提示词。浏览历史仅改变预览，不切换画布输出、模型参数或撤销记录，并保留手动缩放与平移状态；适应状态在更换图片尺寸或窗口尺寸时重新适应，手动缩放保留但不低于新的适应比例。历史缩略图未选中为 60px，选中为 72px，尺寸以 250ms 的 `cubic-bezier(.4, 0, .2, 1)` 同步切换，相邻项随尺寸变化移动；当前项自动滚动到可见区域，支持上下左右键及 Home／End，连续反向操作从当前尺寸继续，减少动态效果时即时切换。主图默认适应可用区域，最多 100%；缩放范围为适应比例至 1600%，支持 1.5 倍增减、适应／原尺寸切换、拖动、以指针为中心的滚轮缩放与捏合。已移除图片平铺功能及其工具栏按钮。退出使用关闭按钮、Escape 或遮罩空白；下载菜单内 Escape 先收起菜单。Tab／Shift+Tab 在弹窗内循环，关闭后恢复触发入口焦点。

全屏入场和退场为 150ms 淡入淡出；布局切换为 80ms，缩放为 100ms ease-out；下载菜单为 250ms 入场／150ms 退场，提示浮层为 150ms／80ms、0.98 缩放。减少动态效果时即时切换。字体、描边图标与颜色取自原版；Geist Sans 复用现有文件，百分比使用原版 Geist Mono。全屏样式限定在组件内。

Masonry 卡片在最外层通过 `clip-path: inset(0 round 16px)` 将图片与模糊遮罩统一裁切一次；遮罩本身不再重复裁切圆角，避免抗锯齿叠加后漏出原图亮边。不改变卡片尺寸、内容排版或遮罩动效。

底部提示词最多 96px 高，独立滚动且不触发图片缩放或画布手势。底部提示词与 Masonry 卡片内提示词的滚动条复用 Flora 的 15px 透明轨道、6px 透明滑块边距、8px 圆角与 `#b5b3ad` 色，不改变提示词栏或卡片的位置和尺寸。图片加载失败时显示原版的 `Asset unavailable`，隐藏缩放控件并停用图片手势；历史缩略图使用原版灰色方块占位。切换到有效历史后恢复图片与控件。

PNG、JPG、WEBP 可下载，格式不同时在浏览器内转换；SVG、Edit 保留原版入口占位，移除 Review generations 入口。单图下载菜单及 Masonry 工具栏的 Download all 将当前节点全部历史图片的原始文件打包为 `images.zip`，复用已有批量下载逻辑，下载期间防止重复启动，失败后提示并可重试。全屏图片信息使用中文标签，名称读取当前素材的真实文件名，模型读取该素材生成记录，格式、大小、分辨率与创建时间读取素材元数据；缺失的格式、大小和分辨率可通过当前图片文件补全，不修改节点数据。保留创建者行，缺少记录时为「—」；不显示 Cost、Seed 或 FLORA ID。导入图与旧素材缺少的字段保留「—」。Flora 在小于 768px 时切换为只读画布，本轮没有可独立对照的手机全屏页面。

图片信息的标题为 14px；详情采用 12px 字号、16px 行高容器和 8px 行间距，标签与数值分别使用 12px / 13.5px 文字行高。详情底部保留 8px 留白，左右内边距 12px，与 FLORA 保持一致。

图片信息与共用的「生成选项」面板统一使用 `rgb(25 25 24 / 90%)` 底色和 16px 背景模糊，不添加额外投影。

「生成选项」标题可以折叠；侧栏操作不拖动或缩放画布，锁定后禁用参数编辑，仍可查看图片信息与预览。参数修改进入画布撤销记录并随项目保存；多选或取消选择时隐藏侧栏。下拉菜单在画布面板上方使用屏幕坐标，并支持方向键、Enter 和 Escape。

生成选项中的二级菜单使用 Radix Select：菜单按内容自适应宽度、最大高度 320px，12px 圆角与 16px 背景模糊；选项高 40px，使用 8px 圆角和 12px 水平内边距。工具栏比例菜单同样最多 320px；两处均受视口可用高度限制，超出内容通过细滚动条访问，滚动不影响画布。方向键及 Home / End 可移动焦点并滚动到对应选项，Enter 确认、Escape 关闭并回到触发按钮。悬停高亮独立于选中勾选，点击确认后收起。指针打开和关闭分别采用 150ms / 80ms 的 0.97 缩放淡入淡出；键盘操作及减少动态效果设置下即时切换。

出图后可从结果图片区域拖动整个节点。主画布通过 `canvasImageDrag` 统一拦截结果图（含淡入淡出层）和历史缩略图的浏览器原生拖拽；保留提示词编辑、历史切换、端口连线与锁定行为。

Image 与 Text 共用的历史缩略图在展开时为滚动视口添加 `nowheel`，先阻止 React Flow 的原生滚轮缩放，再由历史组件处理横向滚动。历史较多时，滚动不会平移或缩放画布；收起后恢复画布的滚轮行为。

Image 与 Text 左侧的两个输入端口以节点中线为中心，默认分别偏移 −20px／+20px，中心距 40px。磁吸沿用 FLORA 的 160px 感应半径、35% 吸引和最多 20px 位移；两口可接近到 26px 中心距，24px 的圆环区域仍有 2px 留白（均按画布 100% 计算）。逐帧约束圆环间距，连续反向移动和减少动态效果下也不重叠；不额外撑开标签按钮。三个输入入口共用 [InputPortRing](../../components/image-prompt-node/InputPortRing.tsx)：半径 10px、1.5px 圆头的八段虚线，连接圆点半径 3.84px；按设备像素和缩放补偿半像素外沿，贴近 FLORA 距离场的边缘覆盖。约束不增加吸附位移，不影响端口 ID、连线和锁定。

Image 生成中的历史缩略图复用 `ImagePromptGeneration` 的纯填充模式，与主图共用任务起始时间及进度曲线，按缩略图圆角裁切；等待项保持空进度，完成后替换为结果图片。查看旧历史不停止待完成缩略图的进度，选择等待项时主图也保持空进度。

## Text 节点

[CanvasTextNode](../CanvasTextNode.tsx) 复用 Image 的标题、卡片、悬停、选中、端口、优化提示词与发送按钮，以及顶部工具栏和模型二级菜单。OpenAI 模型选择已接入真实 Responses API，Tools、连接应用、素材库、发送、评论只展示默认和悬停状态。锁定、提示词、数量、TXT／MD 切换可用。

Text 的输入预览直接复用 [ImagePromptReferences](../../components/image-prompt-node/ImagePromptReferences.tsx)：Text 连入时显示灰色 T 卡片、上游节点名称和 Text 类型；Image 连入时显示当前选中图片，按图片端口顺序排列，Text 在前。首次生成前随底部操作栏在悬停、选中或聚焦时显示；生成中和有输出时移到提示词上方并常显，不随节点取消选中或移出而隐藏，按 DOM 顺序支持键盘访问。Text 参考图标使用独立的描边 SVG 样式，避免继承蒙版图标的实色背景。悬停、键盘聚焦与移出沿用 Image 的展开／收起、图标缩放、名称截断与移除按钮动效。上游改名、图片历史切换和结果更新会同步预览，文本历史切换同步更新下次请求内容（T 图标保持不变）；上游未就绪仍显示对应占位。移除仅断开该条输入连线，可撤销，不删除节点或结果；目标锁定时可展开查看，但不显示移除按钮。预览内操作与滚动不拖动或缩放画布；现有 Text／Image 输入端口、执行输入顺序和历史行为保持不变。

Text 生成期间，连入的 Text 与 Image 连线复用 [WorkflowEdge](../../edges/WorkflowEdge.tsx) 的径向流光与现有几何、速度和减少动态效果规则，光点从上游流向当前生成节点。以整批是否仍有待完成项驱动，查看已完成历史项不停止连线；完成、失败、取消、删除或项目切换后停止。运行信号仅在内存中发布，不进入保存与撤销记录。

Text 固定 384 × 384。运行时提示词保持在顶部，以 16px／26px、500 字重显示，最高 144px；下方分隔线和独立滚动结果区域以 14px／24px 显示。使用 Image 边框扫光，不显示覆盖正文的 Image 进度填充或底部紧凑编辑框。标题和历史卡片沿用 FLORA 的 20 秒视觉估计，卡片填充在 40 秒内以 `cubic-bezier(.33,1,.68,1)` 趋近 95%；它不代表服务商实际耗时或完成进度。

[TextOutput](../../components/image-prompt-node/TextOutput.tsx) 在等待首段时显示 6 × 14px、2px 圆角的光标，以 2400ms 在 0.7 与 1 透明度间呼吸。流式文字按词以 450ms ease-out 淡入，已读前缀不重新淡入；Markdown 光标跟随最后一段文字，代码块保持原文。最后增量和完成事件同时到达时仍保留淡入所需时间；切换历史则立即显示对应结果。默认跟随输出底部，用户向上滚动后停止跟随。TXT 展示原始 Markdown，MD 使用 React Markdown 与 GFM 安全渲染；切换不修改内容，保留相同结果。减少动态效果下光标、文字与边框静止，仍逐步呈现生成进度。

两份及以上结果复用 Image 的 `ImagePromptHistory`，缩略图改用 FLORA 的 T 图标。默认 32px 卡片以 12px 重叠；悬停或聚焦后展开，当前卡片 40px，图标由 10px 变为 12px，显示左右箭头和「n of N」。位置与尺寸投影沿用 250ms 过渡，支持连续反向操作、横向溢出滚动、方向键与 Home／End，减少动态效果下即时切换。选择历史同时恢复该次提示词、模型和输出，保留当前 TXT／MD 格式；锁定时禁止切换。生成中的待完成项通过 Image 的填充动画显示进度，完成后变为 T 图标。查看旧项时主卡片恢复模型名并停止扫光，待完成缩略图继续运行，选择待完成项可返回实时输出。只有成功完成才追加保存记录，结果落入画布与请求状态结束的交界帧不重复显示同一项。

运行按钮通过 [文本客户端](../textGenerationClient.ts) 调用后端 `/api/text`，实时追加模型增量，等待服务商完成事件后一次写入结果与模型、Response ID、时间，避免每个片段写入撤销与保存记录。生成中发送按钮可停止当前请求。失败、断流、取消或超时保留上次成功结果，提示原因；不会自动重新提交。文本与按端口排序的图片均参与请求。

数量大于 1 时，立即在同一个历史组件中放入对应数量的待完成卡片。最多三份同时生成，等待项显示空进度，执行项沿用进度填充，完成项变为 T；生成期间可以在各份实时文本与旧历史之间切换。卡片顺序以提交顺序为准，单份完成不抢走用户主动选中的卡片。失败项在整批结束前可查看错误，结束后仅成功结果留在历史。发送按钮在运行项上停止整批，已完成记录保留；数量与 TXT／MD 切换仍用于当前控件与后续运行。

Text 选中时使用 [TextInspector](../../components/image-prompt-node/TextInspector.tsx) 在右侧以中文显示文本信息和生成选项（包括菜单与参数档位），保留模型名称和用户节点名称，复用 Image 检查器布局、[GenerationOptionsPanel](../../components/image-prompt-node/GenerationOptionsPanel.tsx)、模型菜单和参数下拉组件。空态只显示可编辑名称与禁用的信息按钮；完成后显示当前历史项的模型、原始字符数和创建时间。「本次花费」显示当前历史项的计费快照，悬停金额查看 token、缓存、推理和搜索用量；未计量的旧记录显示 `—`。创建者和更多操作仍为预留。生成中的历史项不借用上一份结果的信息；切换完成项同步信息卡，且不发出生成请求。单选 Text 才显示浮窗，锁定禁用名称、模型、思考强度和网络搜索编辑。

思考强度低／中／高／超高／最高 对应 Responses `reasoning.effort` 的 `low`／`medium`／`high`／`xhigh`／`max`；新建默认中，缺少该字段的旧节点继续低。Luna 菜单中的「无」 仅为禁用占位，避免提交未经支持的值。参数写入 `textComposer.reasoningEffort`，生成记录保存实际使用值，切换历史恢复。思考强度下方增加「网络搜索」行，复用参数下拉显示「关闭／开启」，遵循 Flora 搜索选项的 40px 行高、12px 间隔和 12px 圆角菜单、悬停、选中、键盘及动效规则。默认关闭，选择后只保存设置，手动发送才运行；锁定禁用编辑，菜单可用 Escape 关闭并恢复焦点。「预计费用」随当前模型、提示词（含上游文本与参考图）、思考强度、搜索开关和生成数量更新，前缀 `≈` 标明估算；悬停信息按钮查看假设。修改设置不重算历史的本次花费，也不会自动生成。

DeepSeek V4.1 Flash 在模型菜单默认置顶并标注 APIMart，检查器显示低／高／最高三档，对应 Chat Completions 的 `reasoning_effort`。从 GPT 切换时，中和超高分别显示为高和最高。网络搜索仅在 GPT 模型的生成选项可用。


## Image 的 Prompt 输入

Image 左侧在 Image 上方提供 Prompt 端口。连入 Text 后，节点显示上游当前选中的已完成文本，尚未生成时显示其手写提示词；替代本地草稿，不合并。文字为只读、50% 不透明度，来源以共用的 T 缩略卡片显示，悬停或键盘聚焦展开节点名与 Text 类型。参考图位于 T 之后，仍只对图片排序，T 固定在首位；图片输入计数不包含 Prompt。

生成中及有图片时，图片底部的紧凑提示词面板与 T 卡片在移出、取消选择后保持可见，悬停面板后内容提高到完整不透明度，上游提示词仍保持变淡。空态沿用底部参考卡片的位置。上游修改或切换已完成历史后同步显示并用于下次生成；不使用未完成的流式文本。来源卡片的移除按钮只断开 Prompt，恢复原来的本地草稿；锁定后可查看，禁止断开和运行。保存、刷新、撤销与重做保留连线与草稿。


Text 与 Image 的正文编辑区统一使用 14px 字号、24px 行高，空态占位文字沿用同一行高；Image 紧凑提示词面板也使用此设置。Text 已有输出时顶部的 16px 提示词使用 26px 行高，结果正文为 14px／24px。提及胶囊与菜单保留自身尺寸。

## 提及画布图片

Image 与 Text 共用 [PromptMentionEditor](../../components/image-prompt-node/PromptMentionEditor.tsx)。点击底部 @ 在当前光标处插入 `@` 并打开与 Flora 一致的提及列表；直接键入 `@` 也可触发。列表按 Connected nodes／All nodes 分组，显示当前画布内除自身外的 Image（包括导入图与尚未出图的 Image），按用户要求排除 Text。输入名称筛选，方向键、Home／End 移动高亮，Enter／Tab 确认，Escape 或外部点击收起并保留输入文字；列表滚动不影响画布。

选图用 14px 图片与名称胶囊替换查询，光标回到胶囊之后，参考缩略图复用现有组件。未连接来源接入首个空闲的 `image-0` 至 `image-15`，已有来源复用连线；沿用锁定、环路、容量和自动比例规则。提示词与胶囊偏移保存在各自 composer 的 `mentions`，与新增连线一起进入主画布撤销与保存。胶囊按整体选择或删除，选中时使用更亮的中性底色，不显示描边焦点框；删除最后一次提及只移除由 @ 创建的连线，原有手动连线保留。主动断开参考或删除来源时同步移除该来源胶囊，其余文字和图片输入保留。生成请求在胶囊位置使用 `image 1`、`image 2` 等编号，Kling V4 Image 使用 `@Image1`、`@Image2` 等。编号按最终模型图片数组对应，包含手动参考图、重排及模型对原图的前置／去重；重复提及同一来源复用编号。普通正文中的文件名不替换，编辑器与剪贴板继续保留可读名称。引用来源未包含在模型图片输入时阻止运行，不发送虚假的编号。不将编辑器 HTML 传给模型。

提及列表使用屏幕坐标，缩放不缩小菜单。空态、生成中、结果编辑框和 Text 提示词共用编辑器；锁定及上游 Prompt 只读时禁止 @ 和内容编辑。编辑、胶囊选择、粘贴与菜单键盘操作不触发节点拖动或画布快捷键。

胶囊支持复制、剪切及与正文混合复制。剪贴板同时写入可读纯文本和带来源 ID／偏移的元数据，HTML 属性提供兼容回退；粘贴到当前画布的 Text／Image 时恢复胶囊，多个来源按复制顺序在同一次画布修改中连接，重复来源复用连线。来源不存在、自身或不可连接时降为可读文字；整批连接校验失败时仅粘贴纯文本，不留下部分连线。粘贴元数据不携带图片 URL，缩略图取当前画布来源；普通编辑器只收到名称文字。剪切通过现有删除规则移除最后一次胶囊的自动连线，复制不修改画布。

@ 新建的连线沿真实曲线从来源向目标播放一次 400ms 生长反馈，结束后恢复普通实线；已有连线、撤销重做及刷新恢复不重播。减少动态效果下立即显示完整连线；生成期间继续使用独立的循环流光。

Image 与 Text 的 @ 菜单统一按 Flora 的 Image 样式呈现：屏幕宽 256px、2px 外内边距，列表高至 272px（含边框与外内边距最多 278px）；分组内边距 4px，标题 40px 高，选项 40px 高、图片与名称间距 8px，长名截断；滚动区域为原生 15px 槽，滑块带 6px 透明边框，实际可见 3px，颜色为 `#b5b3ad`，选项可用宽度为 227px。滚动发生在内层列表，外框 16px 与内层 6px 圆角同时裁切，滚动条内缩在边框之内。各分组内按节点加入当前画布的先后倒序，新建空 Image 同样排在前面；文件完成时间及当前结果切换不影响此顺序，不改变图数据或模型输入顺序。两者共用的胶囊以 `vertical-align: -1px` 对齐正文基线，避免使用 `middle` 使后续文字向上偏移。

滚轮只滚动提及列表，不关闭菜单或带动画布；列表内滚动不重新定位弹层，画布变换的重复样式写入也不触发关闭。实际平移、缩放后重新计算光标锚点。方向键与 Home／End 只调整列表自身的滚动位置，不调用会滚动外层画布的 `scrollIntoView`；指针悬停只更新高亮，不强制滚动。


## 节点颜色标记

Image、导入图片与 Text 共用 [NodeColorTagButton](../../components/NodeColorTagButton.tsx)，提供红、橙、黄、绿、蓝、紫、灰七种可叠加标记，None 清空当前节点的标记。标记保存在 `data.colorTags`，按固定色序显示在工具栏和节点标题右侧，支持撤销、重做和项目保存恢复，Image 剪贴板也保留标记；锁定节点禁止增删标记，批量清除跳过锁定节点。

## 导入视频

将 MP4 拖入或粘贴到画布，或按 V 后在视频信息栏选择「导入 MP4」。节点按视频原比例展示，上方显示文件名。悬停或选中显示导入工具栏与底部播放控件，可播放、暂停、静音、调整音量、查看时长和拖动进度。悬停扬声器或用键盘聚焦时，音量滑块在同一块圆角底色上向右展开。滑轨宽 60px，点击扬声器可切换静音，拖动圆点可调节音量。工具栏支持替换视频、颜色标记、下载原文件与全屏播放；Tools 保留悬停提示。视频文件随项目存入 IndexedDB，替换或删除可撤销，播放位置和音量只属于当前播放器。

## 视频生成节点

按 V 或从添加菜单创建 Video。工具栏提供 Seedance 2.5、Kling V4、MiniMax H3 Max 三个模型占位，初始为 Seedance 2.5、16:9、5 秒。可切换 16:9、1:1、9:16，时长按一秒递增或递减，范围为 1–10 秒。模型菜单沿用搜索、置顶、自动选择和多选设置，当前所有选择均运行同一本地预览。选中后可查看视频信息和高级参数。

填写或连入提示词后可运行本地预览。运行时复用节点扫光并保留底部编辑器，可取消。完成后编辑器集成播放、音量与时间轴，可替换、下载或全屏播放。当前三个模型均播放内置的光束微尘样片，导出的 MP4 匹配本次选择的比例和时长。提示词和参考素材为后续模型接入保存在工作流中。
