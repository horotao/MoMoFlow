# 图片标注与交互编辑

[返回节点索引](../README.md)

## 交互编辑

在导入节点选中图片，点右下角「交互编辑」。单击添加点、拖动添加框，每张图片最多 6 个。再次点击按钮或按 Esc 退出。标注按原图保存，切换图片后可回来继续编辑。点和框坐标相对原图归一化到 0–999。标注模式下按 Cmd/Ctrl + Z 撤销，按 Cmd/Ctrl + Shift + Z 重做。

图片模型的静态栅格结果也能直接标注。将鼠标移到结果预览，再点击「排序方式」左侧的「交互编辑」。首次开启会创建绑定该图的提示词和 GPT Image 2.6 节点，将提示词接到 Prompt、原模型的 Result 接到 Image。新模型采用支持标注的渠道和静态输出，输入可编辑后手动运行。点框缩略图随标注更新，再次编辑同一张图时复用已连接的链路。旧画布已有对应提示词时会复用它并补建下一轮模型。切换上游展示时，绑定结果的链路仍使用原先标注的图片。

为新节点腾出位置时，提示词优先向上推开挡路节点，新模型优先向右推开。直接挡路的节点先动，沿途的相邻节点根据碰撞顺序错开起步。节点即将接触时，后一个节点提前跟随。原图、已复用的提示词和锁定节点保持原位，遇到固定障碍时会改用其他方向或为新节点另找位置。指针点击触发 380ms 减速平移，连线随节点移动。键盘激活和减少动态效果模式直接落位，新建、连线和让位作为一次撤销记录。

悬停点标注编号、框内或框标注编号时显示移动光标，可以拖动对应标注。拖动整框时保留原宽高。拖动四角的白色手柄可以调整大小，对角保持固定。移动和缩放都限制在图片范围内，松手后更新坐标、保留已有连线，并可通过撤销快捷键恢复。悬停标注编号或用 Tab 聚焦其右上角的减号按钮，可以移除该标注。

把导入节点的图片输出和提示词输出接到同一个图像模型。提示词末尾会自动插入对应的行内缩略图与编号，悬停时可查看原图和标注位置。从图片或提示词删除标注时，对应的点或框及行内引用会一起移除，撤销可恢复两处。若原图节点已锁定，只移除该提示词中的引用。复制纯文本时，标注解析为 `<point>x y</point>` 或 `<bbox>x1 y1 x2 y2</bbox>`。Seedream 使用这些坐标并自动提交对应的原图。

打开旧画布时，独立交互编辑节点的标注会迁到来源导入节点，已有行内引用继续指向原标注。来源是图片模型时，可恢复的已标注图片转换为 File 快照。

GPT Image 2.6 会从提示词读取交互编辑标注，自动把标注原图放到首位，合并重复接入的原图，其他图片按端口顺序作为参考。每次运行可标注一张原图，使用静态图片输出，且不能同时连接 Mask。不同原图的标注需分别连接提示词和 GPT Image 节点。

- OpenAI 官方与 APIMart 标准版通过透明标注图定位编辑。浏览器将点和框渲染为原图同尺寸的透明 PNG，提示词引用红圈、红框及编号，原图最多 16,777,216 像素。OpenAI 官方以 multipart 的 `markup` 字段提交。APIMart 标准版先将原图、参考图与标注图上传到 `/v1/uploads/images?retention_days=3`，然后以 `image_urls` 和 `markup_url` 提交编辑。
- APIMart GPT Image 2.6 EXT 使用普通提示词和参考图。提示词包含有效的交互编辑标注时，运行前会提示切换到 APIMart 标准版或 OpenAI 官方渠道。
- APIMart 的浏览器 API Key 配置使用直传。本地环境变量 Key 由开发服务器代传文件，两种方式都先取得文件 URL，再创建生成任务。
