# 节点创建与连接

空白画布右键和左侧加号打开同一个「添加节点」菜单，提供「图片」，支持搜索、键盘选择及一次创建 1–20 个 Image。右键创建的位置取自点击处，左侧加号创建的位置取自当前视野中心。

Image 的右侧「+」可在生成前起拖。拖到另一个 Image 左侧的图片输入会建立连接；拖到空白处可创建下游 Image 并自动连线。从图片输入反向拖到空白处可创建一个上游 Image。关闭菜单取消创建，一次撤销同时移除刚创建的节点及连线。

## 输入输出与交互约定

源端口为 `result`，目标端口为 `image-0` 至 `image-15`。每个图片输入槽只接收一条连线。禁止自连接、环路、重复来源和涉及锁定节点的连接。提示词在 Image 内编辑。保存和刷新沿用相同的节点与端口 ID。

导入图片提供 `result` 输出，可拖线到 Image 的图片输入。替换图片后，同一条连线会提供新素材。从下游 Image 的参考图缩略图移除输入时，仅断开对应连线。接入两张及以上参考图时，可拖拽缩略图调整顺序；松手后一次性重排现有图片输入槽，保留连线 ID、来源与其余连接。缩略图、自动比例所用的首张参考图及模型请求中的图片顺序保持一致。排序支持一次撤销、重做和保存恢复；目标节点锁定时禁用排序。

主画布使用快照的贝塞尔曲线与分段算法。拖动时白色 2 单位虚线沿手势方向流动，每 600ms 移动一个周期；进入或离开兼容端口的 40 单位吸附范围时，线头以 120ms 缓出过渡。减少动态效果时使用静态虚线并直接定位。松手后线条为 3 单位半透明灰色实线，悬停显现两端 Image 端口，选中或键盘聚焦时提高线条亮度。线宽随画布缩放。

选中节点时，其所有直接连入和连出的线同步使用选中亮度；多选时取所有选中节点的相邻连线，取消节点选择后恢复。此高亮不改变连线自身的选择状态，删除、复制等操作仍按实际选中项执行。

Image 生成和结果切换期间，两侧端口继续参与布局。已有连线跟随端口，悬停时仍可查看端点。

鼠标进入某一端口锚点的 160 节点单位范围时，该侧端口提前显现，同时以 35% 拉力、最多 20 单位位移朝鼠标移动。显隐和水平展开使用独立的 150ms 过渡，磁移使用 500ms 缓出；连续靠近、反向和离开均从当前状态继续。范围随画布缩放，平移、拖动和节点尺寸变化后重新计算。锁定或当前拖线中不兼容的端口不触发靠近显现；节点与连线原有悬停反馈保留。触屏不保留鼠标靠近状态，失焦或鼠标离开页面时清理。减少动态效果下直接切换显隐和位置。
