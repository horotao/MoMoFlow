# Image Crop 验收

2026-11-23，在 Flora 当前项目实操 Crop 后实现；本地使用独立站点存储 `http://127.0.0.1:5181/` 的实际主画布验收。不是隔离组件页；没有调用真实模型、部署或核验生产站点，也未替代用户本人手动验收。

Flora 观察覆盖 Tools → Crop、原图展开、其他节点压暗、框外遮罩、白色四角及四边手柄、拖动、Enter 应用、Escape 取消及再次进入恢复范围。验证结束后，参考图恢复为进入前的 927 × 854 裁剪尺寸。未将 Flora 的撤销快捷键视为裁剪撤销依据；本地使用现有主画布历史单独验证。

本地主画布浏览器模拟操作：

- 受控粘贴导入图和生成结果夹具；导入图再通过实际文件选择器替换为本地 PNG Blob。图片来自仓库 `tests/fixtures/image-node-1.png` 与 `image-node-2.png`。
- 从 Tools 和图片信息栏进入裁剪；导入图在 100% 下拖动左上角，得到 1236 × 972；在 69% 下对真实本地 Blob 裁剪为 1319 × 978。生成图裁剪为 869 × 869。通过图片实际 `naturalWidth`／`naturalHeight` 核对编码结果。
- 再次进入展开完整原图并恢复原图像素矩形；方向键调整 1 像素，Shift 方向键调整 10 像素。Escape 取消后像素尺寸不变，确认后焦点回到当前节点 Tools，Cmd+Z 与 Cmd+Shift+Z 单步恢复裁剪前后结果。
- 框内向左上拖动 20 屏幕像素，框位置同步移动而宽高保持 869 × 869；Escape 取消后重入恢复已保存位置。用角点向外扩展至完整 1024 × 1024 后确认，可恢复原始文件。信息栏与 Tools 两个入口均复验了确认后的撤销焦点。
- 从导入图的 result 拖线到生成图 image-0；裁剪后下游参考缩略图与来源输出使用相同 Blob URL，实际像素尺寸同步。拖动有内容的生成节点后，节点、连线与小地图几何同步。
- 小地图显示两节点及连线。检查 14%／69%／100%／200% 缩放；14% 与 200% 下手柄命中框均为 24 屏幕像素，角标为 14 屏幕像素。远缩放下键盘调整仍正确，取消不写入图数据。
- 锁定生成节点后 Crop 菜单项禁用，解锁恢复；通过实际添加菜单新建 Image 空态，工具栏 Crop 与信息栏裁剪按钮均禁用，之后单步撤销新建。
- 开启页面级减少动态效果模拟，方向键裁剪仍正确，裁剪框过渡为 0s；关闭模拟后恢复默认设置。
- 刷新后两张裁剪图分别恢复为 1319 × 978 和 869 × 869，连线仍在；重新打开导入图裁剪时，原始本地 Blob 和已保存裁剪矩形同时恢复。
- 点击工具栏下载未出现页面错误，但浏览器自动化下载事件未返回；另用图像导出核对当前 PNG 文件为 869 × 869。该项仅证明裁剪文件字节正确，未将下载事件捕获计为通过。

自动检查通过后归档。几何约束、原图 Blob 引用、裁剪图与原图的存储映射均加入既有 `npm test` 入口；完整校验使用 `npm run check`。

## 裁剪时的背景亮度修正

2026-11-23 按用户截图重新对照 Flora：在同一视口截取裁剪中和 Escape 退出后的画面，图片区域的 RGB 比值中位数约 0.395，连线约 0.399，标题约 1.0（JPEG 采样存在压缩误差）。据此将非当前节点的内容及连线设为 40% 亮度，不再对节点整体施加 8% 不透明度；名称、模型标签和标题色标保留原样。

本次浏览器模拟复验使用独立存储的实际主画布：分别从生成图和导入图进入裁剪，检查 69%／100% 缩放下另一节点的标题、模型标签和图片内容；节点整体不透明度保持 1，标题与模型无额外滤镜，内容及连线为 `brightness(0.4)`。Escape 后两张图片和连线的滤镜均恢复 `none`，裁剪尺寸与一条已有连线不变，小地图正常，控制台无错误。本轮仅调整 CSS，未新增模型流程或部署，未做用户本人手动验收。

参考检查期间误触了 Flora 放大图片操作；取消活动任务后，按用户授权清理了产生的两个临时节点，不将该调用作为 Crop 的真实模型验证。

## 裁剪期间平移画布

2026-11-23 修正中键和空格拖动被当作外部确认的问题。非左键按下不再触发外部确认，空格键交给现有 React Flow 平移快捷键；按住空格时让节点及手柄的鼠标命中穿透到画布，松开空格或窗口失焦时恢复。中键或空格拖动都不提交裁剪，也不修改当前未确认的像素矩形。普通左键外部点击仍确认，Enter／Escape 规则保持。

本地独立存储的实际主画布浏览器模拟：

- 69% 生成图：先以方向键调整未确认的框，再从空白处、原图内部和聚焦的手柄开始平移。中键移动 60×30 屏幕像素、空格反向移动，视图坐标随指针变化，裁剪框百分比不变。
- 松开空格后，手柄左键拖动可继续调整范围，画布坐标不变；Escape 恢复原有 869×869 结果。
- 100% 导入图：Shift 方向键调整 10 原图像素，再从手柄使用中键平移、从框内使用空格平移，待确认范围不变；Escape 恢复 1319×978。
- 14% 和 200% 缩放下分别进行中键平移及空格反向平移，裁剪始终保持，范围不变。减少动态效果开启时平移也保持直接跟随，验收后已恢复默认设置。
- 普通左键外部点击仍退出裁剪；退出后节点恢复鼠标命中，节点坐标与一条已有连线不变，小地图正常，控制台无错误。

本轮没有访问 Flora 或调用模型，未部署，也未替代用户本人手动验收。完整自动检查使用 `npm run check`。
