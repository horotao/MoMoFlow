# 节点工具栏提示验收

2026-11-23，在 Flora 已打开的实际项目观察交互，再在独立浏览器存储 `node-toolbar-tooltips` 的本地实际主画布复验。未调用真实模型、未核验生产站点，以下为代理操作及浏览器模拟结果，不代表用户本人手动验收。

Flora 首次 Lock node 提示从 pointerover 至挂载约 307.9ms，Download 重新悬停约 303.8ms；相邻按钮切换出现 instant-open。计算样式为上方间隔 4px、12px 圆角、4px／8px 内边距、12px／13.5px GeistSans、16px 模糊、`#0000004d` 背景及 `#fafaf223` 边框；入场 150ms、退场 80ms、缩放 0.98、曲线 `cubic-bezier(0, 0, .2, 1)`。

本地首次 Lock node 约 306ms 后进入 delayed-open；随后颜色标记为 instant-open。覆盖 Image 空态、Text 空态、导入图片内容、禁用下载及素材库入口、颜色菜单点击与 Escape、模型菜单方向键打开与 Escape 恢复焦点、锁定与解锁。键盘提示无动画，Escape 关闭提示保持节点选中；模型菜单操作不再将方向键传给画布。

83% 与 100% 缩放下「锁定节点」均为 66 × 23.5px。减少动态效果下实测 animation-name 为 none。浏览器模拟经真实节点标题拖动处理器将 Text 从 (720, 505) 移到 (792, 433)，经真实端口鼠标处理器连接导入图至 Image 的 image-0；缩放、小地图与参考图比例同步正常，刷新恢复 3 个节点、1 条连线和小地图节点。普通工具栏操作不修改节点位置；撤销／重做导入图恢复正常。
