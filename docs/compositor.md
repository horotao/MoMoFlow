# Compositor 静态图像合成

在 **Tools → Editing → Compositor** 创建节点，或从图片输出拖到空白画布，在推荐菜单选择 Background / Layer 1。默认两个图片输入；`+ Add layer` 增加稳定编号的输入，最多 64 个图层。每个端口只接收一个上游，文件集合取第一张图片。右侧 `result` 端口显示为 Output，可连接 Preview、其他图像处理节点、Sunburst 的图片/遮罩输入和 Image Describer。

节点预览按画布宽高比显示，高度随图片和输入端口数量适配。鼠标悬停在预览上时显示左下角像素尺寸和右上角下载图标，离开后隐藏；键盘 Tab 聚焦下载按钮时也会显示。预览下方的操作栏左侧为 **Add layer**，右侧为 **Edit**；点击 Edit 打开三栏编辑器。画布编辑全部在浏览器本地完成，无需运行模型。

## 编辑方式

- **Layers**：从上到下显示从前到后的图层。单击选中，双击名称、F2 或菜单 Rename 重命名；拖放排序，插入线区分目标行的上方/下方；也可聚焦图层后用 Alt+上下方向键，或在右键/省略号菜单中前移、后移。眼睛控制显示，锁控制编辑。Delete 删除普通图层；输入图层删除时同时移除相应端口和连线，撤销可一起恢复。Background 保留输入位置，允许隐藏、变换与添加效果。
- **Assets**：列出当前工作流可用图片及当前合成使用的素材，单击查看图片预览、原始尺寸与 Add to canvas；也可将缩略图拖到画布，在落点居中添加独立图层。支持按文件名搜索，缩略图角标显示当前使用数量。独立图层引用当前素材快照；输入图层继续跟随上游更新。
- **Canvas**：拖动图层移动，八个方向的手柄缩放，右上圆形手柄旋转。缩放手柄保持 7px 可见尺寸和 20px 命中区域，选中框独立于图层堆叠，选中的底层图片也能操作手柄。缩放遵循比例锁，Shift 临时切换；Alt 从中心缩放，普通缩放固定对侧角点或边中点，旋转后仍保持锚点。移动时按 6px 屏幕距离吸附到画布或其他可见图层的边缘/中心，并显示辅助线；旋转图层使用旋转后的外接边界。Shift 约束移动方向，Ctrl/⌘ 暂时关闭吸附。旋转靠近直角时自动吸附，Shift 按 15° 吸附；跨越 ±180° 连续旋转不跳变。操作时显示坐标、尺寸或角度，Escape 取消；小于 3px 的点击抖动不创建编辑记录。图片在画布边界裁切，保留完整素材。
- **Properties**：未选图层时设置画布；选中图层时设置位置、六种对齐、宽高和比例锁、旋转、透明度、混合模式、矩形内描边及效果。数字输入 Enter 或失焦提交，Escape 取消未提交输入。Reset to fit 恢复图层的自动居中适配。
- **Fill / Stroke 颜色**：点击色块打开编辑器内的取色浮层，提供饱和度/亮度色板、色相条和 HEX 输入，适配深浅主题。拖动实时预览，松手只提交一步撤销；Escape 取消当前拖动。色板支持方向键微调、Shift 十步调整。HEX 接受 3 位或 6 位色值，Enter、失焦或点击浮层外提交；无效值及 Escape 恢复原值。填充透明仍通过 Fill 减号切换，不改变保存格式。
- **Effects**：支持 Blur（Box / Gaussian）、Color correction（七项参数）、Invert 和 Levels（RGB/R/G/B 通道，Inputs 三手柄、Outputs 双手柄）。侧栏显示紧凑效果列表，点击名称向左打开参数浮层；滑块实时显示草稿，松手提交一次历史；Blur / Color correction 也可精确输入数值。Levels 的输入黑场、中间调、白场共用一条轨道，输出黑白场共用另一条轨道；中间调按现有对数映射转换为 Gamma，不改变保存格式或像素算法。手柄支持方向键微调、Shift 十步调整、Home/End 和 Escape 取消拖动。按列表从上到下处理，可拖动排序，或使用参数浮层底部的顺序按钮；聚焦效果名称时 Alt+上下方向键也可排序。眼睛启用/禁用，减号移除，最多每层 16 个效果。直接调用现有节点的像素算法，原始图片不变。Escape 关闭浮层并将焦点还给触发控件。

底部工具栏按选择、平移、文本、钢笔、形状、撤销/重做、缩放的顺序组织。形状菜单提供 Rectangle、Ellipse、Triangle 和 Star；菜单提供放大、缩小、100% 和适配画布。菜单支持方向键选择、Enter 执行、Escape 关闭并还原焦点。

快捷键：V 选择、H 或按住 Space 平移，滚轮平移，Ctrl/⌘ + 滚轮缩放；`+` / `-` 缩放，`0` 或 Shift+1 适配，Ctrl/⌘+0 显示 100%；方向键移动 1px、Shift+方向键 10px；Ctrl/⌘+D 复制选中图层；Delete/Backspace 删除；Ctrl/⌘+Z 撤销，Ctrl/⌘+Shift+Z 或 Ctrl+Y 重做。Escape 依次取消当前手势、清除选择、关闭编辑器。编辑器捕获这些快捷键，防止删除或复制底层工作流节点。

## 文本、钢笔和形状

- **文本（T）**：单击创建默认文字框，也可拖出指定尺寸；输入支持中文、多行、换行。双击文字、使用文本工具点击已有文字，或点击右侧 Typography 的编辑按钮重新输入；编辑时使用透明的原位输入层，保留画布效果、垂直对齐、原生选区、光标及输入撤销。Ctrl/⌘+Enter 或移开焦点提交一次历史，Escape 取消本次文字修改。右侧可调整 Inter / 系统字体、字重、斜体、字号、行高、字距、水平/垂直对齐和填充。改变文字框尺寸会重新排版，字号独立控制。单层文字上限 10,000 字符。
- **钢笔（P）**：单击逐个添加锚点，按住拖动创建对称的 Bézier 控制柄，Shift 约束下一段的方向；单击起点闭合，Enter 或双击结束开放路径，Escape 取消，Backspace 删除最后一个点。双击已完成的矢量或点击 Edit path 可编辑锚点；锚点为 8px 方块、控制柄为 6px 圆点，均有固定 20px 屏幕命中区。允许拖出原图层边界，自动重算边界并保持其他锚点的位置；旋转后的路径也按局部坐标正确调整。平滑控制柄默认联动方向，Alt 独立调整，Shift 约束轴向或 45°；双击锚点切换平滑/折角，Alt 拖动折角生成对称控制柄。双击曲线在点击处插入锚点并保持曲线不变；方向键移动 1px，Shift+方向键 10px；Delete 删除所选锚点（开放路径至少两个、闭合路径至少三个），Enter/Escape 退出锚点编辑。未完成路径的撤销只移除最后锚点，不撤销之前的文档编辑。支持填充、描边颜色/宽度、连接方式和端点样式；最多 2,048 个锚点。
- **形状（R / O）**：矩形、椭圆、三角形、星形。拖拽创建，Shift 等比，Alt 从中心绘制；单击创建默认 200×200 图层。绘制中显示固定屏幕线宽的边框与尺寸提示，按下或松开 Shift/Alt 即刻更新约束；Escape 取消。完成后回到选择工具。支持原有变换、吸附、填充、描边、透明度、混合模式和有序效果。

新增内容与图片共用 Layers 的重排、命名、隐藏、锁定、复制/删除和撤销机制，计入同一个 64 层上限；不增加工作流输入端口。源文字、形状类型、归一化锚点/曲线柄及参数保存在 `data.document.layers[].source`，不是图片素材副本。Worker 使用本地 Inter 字体绘制文字；其他字体采用系统字体。不同设备若缺少相同系统字体，可能使用回退字体；默认 Inter 随项目提供。

新增图层先按原尺寸绘制，再经过既有图像效果和统一合成流程。交互草稿为矢量栅格设 512px 最长边，最终输出按图层和画布原尺寸绘制；粗描边和模糊预留透明边界，避免截断。新增图层与图像效果共享有上限的栅格缓存。版本 1 文档增加了可校验的 `text` / `shape` / `path` 联合类型，旧图片文档继续按原逻辑读取。

## 尺寸、输入和输出

默认透明画布；有 Background 时按实际解码尺寸自动确定宽高，缺少背景时为 1024×1024。手动改尺寸后退出自动尺寸模式，重新勾选 Auto size from Background 可恢复。画布比例锁仅联动手动宽高，不拉伸现有图层。未手动变换的图片按其原始比例居中适配，不放大；有变换的图层保留像素位置和尺寸。

排序不改变输入映射。替换上游图片时保留图层名称、变换、显示/锁定、透明度和效果。断开普通输入后，该图层成为空占位，参与下一次合成时不再显示旧图片；连接的上游尚未产生有效图片时，输出暂不可用，不输出遗漏部分图层的半成品。隐藏图层不会阻塞合成，但自动尺寸仍需要 Background 的有效图片。

节点预览与编辑器使用同一个合成帧；原尺寸 PNG 来自同一次绘制，可保留透明通道。两条独立 Worker 队列分别负责交互草稿和原尺寸结果；每条队列只保留一个进行中的任务和最新的等待任务。拖动期间输出仍是已提交的版本，松手后使旧输出失效并重新生成。交互草稿合成最长边 1024，其中带效果素材的处理最长边为 512；最终预览最长边 1536，Output/下载保持画布原尺寸。交互期间显示同一次手势中已完成的草稿，避免连续输入让所有预览都失效。提交、取消、上游替换、锁定或新手势会切换预览会话，旧会话不能覆盖当前画面。效果开关、排序、数字提交、撤销等离散编辑也并行请求快速预览和原尺寸结果，不再等待完整效果计算及 PNG 编码后才显示反馈。当前版本的原尺寸帧完成后，较晚返回的低清预览不能覆盖它；预览不发布到 Output。原尺寸输出仍严格检查当前节点、锁定状态、输入和文档版本。草稿效果前缀使用 4MP 像素预算的 LRU 缓存：修改后面的调色不必重复计算前面的模糊，最终输出继续使用原始尺寸的完整算法。效果栅格使用 32MP 上限的 LRU 缓存，保留最近的启用/停用组合，并让同源同参数的图层复用处理结果；键包含源地址、启用效果的顺序/参数及处理比例。替换素材会清除旧源缓存，不因图层 ID 或停用效果参数变化重复处理。

为限制浏览器内存，单张素材和画布最长边 8192、最多 32MP；一次合成需要解码的不同可见素材总计最多 64MP（自动尺寸的背景也计入），带效果图层的处理像素总计也限制为 64MP。缓存按总像素限制回收。图片链接需允许浏览器跨域读取；失败会显示错误，不能把旧图像当作新输出。当前实现需要支持 Worker、OffscreenCanvas 和 createImageBitmap 的现代浏览器。

## 状态与代码结构

- `src/nodes/compositor.ts`：版本化文档、输入身份、非破坏性图层、效果、变换几何、剪贴板验证和输出版本计算。Timeline 保存 enabled、duration、fps 和空 tracks 结构；本阶段仅静态帧，不运行视频或关键帧。
- `src/nodes/compositor/CompositorNode.tsx`：节点 UI、实时图输入解析、结果发布、草稿/原尺寸请求调度与编辑器挂载。
- `CompositorEditor.tsx`、`CanvasSelection.tsx`、`EditorSidebar.tsx`、`EditorToolbar.tsx`、`EditorPopover.tsx`、`Properties.tsx`、`InspectorControls.tsx`、`ColorField.tsx`、`LevelsEffectControls.tsx`、`Compositor.css`：图层/素材面板、工作区手势、属性、浮层控件和快捷键。属性侧栏采用 240px 宽、24px 高控件；取色、效果浮层和菜单挂载在编辑器内部以保留焦点及快捷键边界。颜色换算与 Painter 共用 `src/nodes/colorPicker.ts`；`colorPicker.test.ts` 覆盖 4096 个 RGB 采样的无损往返和 HEX 校验。
- `canvasGeometry.ts`：旋转边界、屏幕距离吸附、角度连续性及手柄方向；`interaction.ts`：预览会话与排序。选中框、辅助线和提示仅为编辑器状态，不写入文档或 PNG。图层手势的文档草稿与辅助 UI 按动画帧一起更新，松手同步提交最后一次输入。
- `compositorGraphics.ts`、`drawGraphic.ts`：图形数据校验、创建几何、文字排版、字体加载与矢量绘制；`useGraphicTools.ts`、`TextLayerEditor.tsx`、`PathEditor.tsx`、`GraphicProperties.tsx`：工具手势、文本/锚点编辑和属性；`pathEditing.ts`：旋转坐标、边界重算、平滑柄及曲线拆分；`useFrameDraft.ts`：连续输入按帧合并，提交或取消时清理排队草稿。
- `renderScene.ts`：统一 Canvas 绘制；`effects.ts`：现有算法组合；`renderCache.ts`、`render.worker.ts` 和 `renderer.ts`：素材解码、受限缓存、PNG 导出及请求合并。

编辑文档保存在节点 `data.document`。手势松开只提交一次画布历史；派生图片和输出版本排除在撤销签名外，重命名/锁定/Timeline 设置也不重新分配 PNG。编辑器使用主画布同一份撤销栈；与现有节点一样，撤销栈本身不跨刷新保存。

IndexedDB 保存文档、输入连线、素材和合成结果，使用既有 `AssetResources` 统一引用与释放。复制节点时为每个输入保留素材 fallback 快照，使独立副本无需连线也能继续编辑；新的连接优先于快照，连接中暂不可用的图片不会回退显示旧素材。原始输入节点的正常断开没有快照回退。资源 ID 作为本地图片的稳定身份；恢复时 Blob URL 的变化不会使有效的已保存输出失效，锁定节点也能恢复输出。仍按当前文档和上游身份校验结果。

`sunburstRun.ts` 的输出解析为一次同步读取建立节点/输入边索引，按节点和输出端口缓存校验结果（包含暂不可用的空输出）。共享上游只校验一次，当前递归路径独立检测环路；遇到环路截断的结果不复用。缓存随着该次读取结束释放，下一次编辑、撤销、连接变动或恢复仍重新校验版本，不保存额外素材或跨帧状态。

Enter 在画布焦点下编辑文本/路径或结束钢笔；按钮、输入框和浮层菜单保留原生键盘行为。中文输入法确认、文本换行与 Cmd/Ctrl+Enter 提交继续由输入控件处理。

钢笔进行中，通过 Enter 激活绘图区外的控件（按钮也支持 Space）时，先同步提交路径，再执行控件动作。提交期间保留原选中项，避免属性面板切换或焦点控件被替换；路径创建与随后修改分别进入撤销历史。绘图区内的 Undo 仍逐点撤销未完成的钢笔，不提前提交路径。

## 验证

运行 `npm test`、`npm run lint`、`npm run build` 和 `git diff --check`。`src/nodes/compositor.test.ts` 和 `src/nodes/compositorInteraction.test.ts` 随已有 Node.js 测试运行器执行，覆盖映射、尺寸覆盖、变换、算法组合、输出失效、连接约束、复制恢复和资源引用，以及连续预览会话、排序插入位置、效果前缀缓存一致性与内存上限。八向缩放测试覆盖多种旋转、比例锁、中心缩放及尺寸边界；吸附测试覆盖缩放比例、隐藏/空图层过滤、约束轴和跨越角度边界。

启动 `npm run dev` 后，打开 `/tests/compositor-browser.html`，点击 **Run compositor browser checks**。这是开发测试入口，不包含在生产构建中；使用真实 Worker 和 PNG 解码校验像素，同时在独立临时 IndexedDB 中检查图文一起保存与恢复，测试完成后关闭并删除该测试数据库，不修改当前工作流。检查范围包含透明度、Multiply、变换/描边、四种效果和顺序、草稿一致性、任务合并、断线失效、恢复和错误路径。

`compositorResolution.test.ts` 使用现有 Node.js 测试运行器，覆盖 4/8/16/32 级共享上游的线性校验次数、空输出缓存、编辑/撤销/重连后的失效、Painter 多输出区分和间接环路。`tests/compositor-keyboard.test.tsx` 随上述浏览器检查页运行，挂载真实编辑器并验证按钮/菜单的 Enter 不被取消、画布 Enter 编辑、输入法与文本换行/提交。钢笔回归使用真实 `useCanvasHistory`，检查进行中路径的 Enter 隐藏/关闭、两步精确撤销/重做、单点取消、Space 激活及工具栏逐点撤销；自动检查用合成事件并仅在测试组件内替代指针捕获。可信键盘事件的实际激活另在交互页人工复验。

`/tests/compositor-interaction.html?chain=16` 提供 16 级真实 Compositor → Preview 验收场景，每级 Background 与 Layer 1 共享前级输出，末级含 Blur / Color / Levels。**Measure graph reads** 采样末级输出读取 100 次并显示有效输出数；**Save QA fixture** 保存到独立的 `momoflow-compositor-interaction-qa-chain` 数据库，可刷新检查恢复。默认不带查询参数的交互页保留 4K 多图层场景，两者均独立于当前用户工作流。

浏览器人工验收还应连接真实多张输入，检查图层拖动、缩放、旋转、排序、隐藏、锁定、重命名、删除/撤销，Assets 添加，画布尺寸与填充，Output → Preview / Invert，下载、刷新重开，及主画布拖动/连接/缩放/小地图。本次实现未改动模型请求和计费路径。
