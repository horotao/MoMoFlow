# MoMoFlow 节点改版阶段 0 核对结果

核对日期：2026 年 11 月 3 日。状态：设计规格和代码差异核对完成，阶段 1／2 所需产品决策已确认。实施总计划见 [节点改版计划](node-visual-redesign-plan.md)。

本阶段核对了六组设计、端点主组件、八类参数栏变体及对应源码。用户已确认画布两倍尺寸、工具栏固定屏幕大小、中英标题及图片／蒙版统一浅蓝线。阶段 0 只核对和记录；应用代码实施进入阶段 1。

## 三 现有功能差异与处理建议

### 可以直接按视觉迁移的能力

| 项目 | 代码核对结果 | 实施处理 |
| --- | --- | --- |
| 运行次数 | 已支持 1～10 次，默认 1；位于共用侧栏底部，通过运行时 store 传给执行器 | 改为设计中的滑杆＋数值输入，保持现有范围和运行含义，不新增执行机制 |
| 对比 Reset | 已有，Slider 模式下将分割位置恢复 50% | 迁到顶部栏，保持锁定与禁用条件 |
| 模糊类型与强度 | 已有 Box／Gaussian，强度 1～100，默认 Gaussian 50 | 调整布局；补上便于精确输入数值的入口 |
| 混合模式与透明度 | 已有模式选择、百分比输入和草稿预览 | 原有控件逻辑迁入顶部栏 |
| 蒙版扩张／收缩 | 已有 -100～100，步长 1，默认 0 | 正负数值均保留，不按示例 11 限制范围 |
| 色彩校正 | 已有七项参数；曝光 -5～5、步长 0.01，其余 -100～100、步长 1，默认均 0 | 侧栏复用原参数范围、处理算法与重置逻辑 |
| 色阶 | 已有 RGB／R／G／B、直方图、五项参数；gamma 0.1～10，其余 0～255 | 保留算法和约束，重排控件；原稿 0.76／214 是示例，不是新默认值 |
| 图像描述 | 已有模型选择、系统指令、可编辑输出和参数暴露 | 保留实际模型标识与现有文案，不照抄示例中的品牌拼写 |

运行次数是运行时共享状态，当前不作为每个节点的独立持久化参数。其原型滑杆复用了旧的 `Video duration / Interactive` 组件，点击层仍带 3～10 seconds 名称和跳转，因此不能直接沿用这些范围与原型交互。应使用真实的 1～10 次规则。

代码依据：[DescriberPanel](../src/components/DescriberPanel.tsx)、[运行时状态](../src/components/useModelTasks.ts)、[执行器](../src/nodes/workflowExecution.ts)、[执行校验](../src/nodes/executionGraph.ts)、[对比节点](../src/nodes/CompareNode.tsx)、[色彩校正参数](../src/nodes/colorCorrection.ts)、[色阶参数](../src/nodes/levels.ts)。这修正了总计划初稿中将运行次数列为潜在新增功能的判断。

### 需要安排入口或明确含义的差异

| 项目 | 原稿与代码的差异 | 建议处理 |
| --- | --- | --- |
| 绘图文字工具 | 原稿有文字按钮；Painter 当前只支持画布、画笔、形状、橡皮擦 | 是否新增需用户决定；若延期，应有明确禁用表现，不能做可点击空操作 |
| 绘图其他参数 | 背景色、背景透明度、画布尺寸、硬度、不透明度和多种形状未在紧凑栏完整展开 | 通过工具／大小／颜色弹层承接；矩形按钮保留形状选择入口 |
| 绘图撤销／重做 | 原稿有独立按钮；现有绘制数据纳入画布历史 | 建议先调用现有历史，不另建绘图专用历史栈；需确定是否期望仅撤销笔画 |
| 蒙版提取模式 | 原稿是 Type 下拉；代码是“选择／添加／减去”三按钮 | 按新稿改为下拉，内部仍保留三种模式和原快捷键 |
| 蒙版提取清空 | 原稿只有重新计算，没有清空按钮 | 补入栏内菜单或轻量操作入口；保留生成中取消与图片／蒙版预览切换 |
| 调整尺寸重置 | 原稿未画 Reset，现有代码支持恢复原图尺寸 | 保留重置入口；比例类图标建议仍表示锁定比例，不能兼任两个动作 |
| Nano Banana 蒙版 | 示例模型标题为 Nano Banana，并出现蒙版端点；当前节点没有独立蒙版输入 | 本次建议只呈现真实支持的输入，新增蒙版能力单列任务 |
| 模型设置稿身份 | 图层名是 Nano Banana，实际标题与参数为 GPT Image 2.5／OpenAI／Sunburst | 以可见内容识别为 GPT 设置参考，另外两模型复用视觉而保留自身参数 |
| 背景透明度 | 稿中是开关；GPT 当前背景参数有 auto／transparent／opaque 三种值，且与 JPEG 格式联动 | 需确定三态如何呈现；不可将关闭自动等同 opaque 而丢失 auto |
| “实时预览”开关 | 色彩校正、色阶稿有开关，当前没有该持久化字段 | 阶段 5 已采用每节点挂载会话偏好，仅控制拖动过程预览，提交仍更新正式输出；重新载入默认开启 |
| 参数设为输入 | 当前模型与描述节点支持暴露字段和上游取值，所选面板稿未画该入口 | 保留悬停／聚焦操作按钮和已暴露状态，关联的端点继续可见 |
| 运行、结果与菜单 | 原稿只展示部分结果态，代码还有运行／取消、进度、错误、结果选择、下载、锁定、重命名等 | 为这些能力保留明确入口；隐藏节点底部参数不等于删除运行／素材操作 |
