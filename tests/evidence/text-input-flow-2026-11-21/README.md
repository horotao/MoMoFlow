## 真实流程

- 新建两个 Text，通过真实画布端口连接。上游仅填写「请结合参考图片，用一句中文描述画面主体，不超过30字。」，没有点击运行，下游提示词留空。
- 通过现有图片节点剪贴板协议建立图片导入入口，随后使用「替换图片」文件选择器实际上传 `tests/fixtures/image-node-1.png`，Blob 素材已保存；连接到下游图片端口。
- 仅点击下游发送一次，现有 OpenAI Key 的真实 GPT-6.2 Sol 调用返回 HTTP 200。请求为上述手写文字、1 张图片；输出「一名戴橙色帽子的男子正把一个巨型西瓜往坡上推。」，用量计费快照 $0.005489。见 `real-flow.json`。
- 上游始终没有结果区域和历史，查看上游信息为未生成状态。刷新后仍保留 3 节点、2 连线、实际下游结果和上传图片。
- `local-before-run.jpg`、`local-generating.jpg`、`final-flow.jpg` 分别记录首次运行前、等待首段及最终完整流程。最终图为 55% 实际主画布；浏览器标签页保留供查看。

- 下游补充「请按上游文字要求描述参考图。」后运行，GPT-6 Luna 完成，输出「橙帽男子在蓝天下的斜坡上奋力推动一个巨大的西瓜。」，上游历史仍为空。最初下游无自身提示词的 UI 点击仅产生建议，未留下生成记录；没有把这部分计作成功调用。

## 历史同步与交互

- 独立旧 QA 项目「Text 参考缩略图验收」通过 CDP Fetch 模拟两份明确可区分的上游文本输出。切换第 2 / 3 份历史后，分别捕获下一次下游请求：输入随历史改变，均携带 1 张图。模拟请求均在浏览器完成，不提交服务商、不额外计费，见 `history-simulation.json`。
- 图片切换第 1 / 2 份后，下游参考缩略图 src 立即切换至对应素材，见 `history-image.json`。文本 T 图标保持原样，所传文字变化。
- 实际指针测试：默认、悬停展开、移出、Text 和 Image 各自移除（只减对应连线）、一次撤销恢复；锁定可查看且无移除按钮；55% / 70% / 100% 缩放；减少动态效果时预览 transition 为 0s，随后恢复系统设置。
- 节点移动后连线保持，缩放及小地图开关可用。控制台无 error。清除了 Fetch 拦截和减少动态效果覆盖。
- 新增自动回归覆盖：未生成文本与上传图片进入下游、上游无副作用、手写修改同步、费用解析一致、已完成历史优先、空上游拦截。其余现有 Text 引用和模型测试继续运行。
