# Image 的 Prompt 输入验收

本地实际主画布 `http://localhost:5173/`，使用独立浏览器存储 `image-prompt-2026-11-22`，项目「Image Prompt 端口验收」。未触碰日常项目数据。本次没有提交、推送、部署或调用真实模型。

自动检查：`npm run check` 通过，313 个测试通过，含三种图片模型的 Text Prompt 执行、空输入阻止运行、锁定、环路、输入类型、快捷创建与混合旧项目迁移回归。新增测试接入既有 `npm test` 入口。

浏览器自动化与事件模拟：在主画布从 Text 正向拖入 Image Prompt，确认只读与 T 来源卡片；从 Prompt 反向拖到 Text 输出，确认三条连接及文本恢复。端口的不可见 div 在测试期间临时添加 ARIA 名称以定位，刷新后消失。测试工具直接拖动按钮未能稳定落在磁性锚点时，使用实际 DOM 鼠标事件验证反向连接；返回 connectingto valid，再松手完成。

受控生成：拦截 `/api/sunburst`，返回本地市场照片夹具。只提交一笔 Image 请求，Prompt 为上游手写原文；Text 没有新历史，没有 `/api/text` 调用。照片用于结果布局验收，不代表模型按茶壶提示词生成的内容。第一次运行夹具仅修改 provider 而未转换尺寸，被运行前校验正确阻止；使用实际设置转换后完成受控请求。

界面核对：首次生成前显示来源卡片；有结果时，未选中、未悬停、未聚焦的底部面板仍为 visible / opacity 1；文本为只读、opacity .5，T 卡片展开显示来源名称与 Text 类型。移除 T 仅断开 Prompt，恢复本地草稿；画布聚焦后撤销恢复连线。锁定禁用运行和端口，移除按钮不渲染。

历史与共享组件：Text 历史切换同步 Image 提示词；Image 切换到第二份历史后仍保留本地草稿。混合 T 与两张参考图时，T 不可排序且固定在首位，图片计数为 2/16；键盘 Space / ArrowRight / Space 成功交换图片，视口不变。Text 场景与既有 Image 图片卡片共用同一参考组件。

导航与恢复：核对 50%、80%、100% 缩放，开启小地图、节点键盘坐标移动及减少动态效果。指针拖动节点的测试工具未产生移动，本次不把它记作拖动手工实测通过。刷新后 Prompt 连线、图片排序、当前 Text / Image 历史与本地草稿均保留，底部预览常显。当前报告属于浏览器自动化与事件模拟，没有人工手势实测或生产验收。
