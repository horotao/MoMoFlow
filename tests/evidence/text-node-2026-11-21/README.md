# Text 节点主画布验收 · 2026-11-21

参考为用户当前已打开的 FLORA Text 节点。先观察空态、聚焦、模型工具栏、TXT／MD，再在 FLORA 运行一次 Claude Sonnet 5 文本生成，核对等待光标、顶部提示词、分隔线、逐步输出、自动滚动和完成态。随后实现本地版本。

本地验收在 `http://localhost:5173/` 的实际主画布新建项目中进行，与用户使用的 `http://127.0.0.1:5173/` 分开存储。使用浏览器工具驱动点击、输入、指针拖动及键盘操作；没有使用隔离测试页替代主画布，也没有安排人工验收或生产部署。

- 左侧菜单与右键均显示文本入口；空态 Tab 可填入建议词。
- 节点标题拖动正确，节点内编辑和结果滚动不拖动画布。
- 模型菜单共用 Image 组件，OpenAI 三个占位选项可搜索、键盘选择；切换后更新标题右侧模型名。
- 首次和再次运行均在卡片顶部保留 16px／22px、500 字重提示词，下方为分隔线和 14px／17.5px 输出；没有进入 Image 底部紧凑编辑状态。
- 生成中块状光标存在，复用 `image-node-generation-sweep` 边框扫光，隐藏 Image 进度填充。连续运行会清理前次演示计时器。
- TXT／MD 可切换同一结果；MD 标题、段落、粗体、列表和引用可预览。核对 FLORA 二级标题为 18px／27px、600 字重。
- Tools 与指定辅助图标为默认及悬停占位，点击不打开功能；生成前显示闪电图标，生成后显示发送图标。
- 锁定后提示词只读，发送、格式、模型与端口不可编辑；解锁后恢复。
- Text 输出拖到空白处只推荐 Text，并自动连线；一次撤销移除新节点和新连线，重做恢复。
- Text 输入反向拖线可创建上游 Text 并替换原连接，一次撤销恢复原连接。
- Image 输出可接入 Text 的 Image 端口，计数更新为 1/16。Text 接收文本和图片，源端口类型分别校验。
- 刷新后 3 个节点、2 条连接、GPT-4o 选择、MD 格式和完整结果均恢复。
- 小地图可展开。核对 14%、60%、100%、200% 缩放；14% 与 200% 下选中节点工具栏屏幕高度均为 42px。最终恢复到 100%。
- `prefers-reduced-motion: reduce` 下工具栏过渡为 0s，光标与扫光的 `animation-name` 均为 `none`，文本仍逐步追加；测试后移除模拟。
- Image 共用工具栏、图像模型菜单与侧栏模型入口已做浏览器回归；未运行本地图片模型。

自动检查 `npm run check` 通过：281 项 Node.js 测试、ESLint、类型检查、生产构建、节点文档及补丁空白检查。新增的语义测试位于 `src/nodes/canvasText.test.ts`，已纳入实际 `npm test` 入口。原连接推荐测试的「仅 Image」预期按本次新增兼容 Text 的需求更新，已对照已提交基线确认差异原因。
