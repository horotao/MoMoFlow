## 计费边界与自动检查

费用使用 API 实际用量与 2026-11-21 官方公开单价快照计算，最终以组织账单为准。缓存读取、30 分钟／12 小时写入独立计费，推理已包含在 output tokens 中，不重复加算。搜索使用可计费次数，不把引用或打开网页次数当作收费次数。未知渠道费率、未知处理档位、搜索用量缺失、无法判断多轮长上下文计费时保持总金额未知。

预计费用是整批参考值，受文本、图片、模型、思考强度、搜索与数量影响；不是上限或最终账单。实际费用与费率快照逐条保存在历史，后续价格和参数修改不会回写旧项。

自动测试覆盖三个模型、输入／缓存／缓存写入、推理不重复计费、搜索零次与多次、长上下文和处理档位、无效／缺失用量、第三方渠道、金额校验、估算变化、上游内容、每份批量历史及保存恢复、SSE 传递。`npm run check` 通过 308 项测试，最终日志为 `.codex/text-cost-check.log`。
