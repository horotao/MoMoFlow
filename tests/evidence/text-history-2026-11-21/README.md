# Text 生成历史验收

2026-11-21，本地实际主画布 `http://localhost:5173/`，与用户的 `127.0.0.1` 使用独立浏览器存储。参考为用户指定的 FLORA 项目既有三份 Text 输出，未额外运行 FLORA。

- 复用原有 ImagePromptHistory；Image 历史组件及其 CSS 未改动。Text 使用参考页面的 T 图标，收起卡片 32px、重叠 12px，展开当前项 40px，图标 10px／12px。
- 实测 FLORA 和本地布局投影均为 250ms、`cubic-bezier(.4,0,.2,1)`；淡入淡出 150ms，缩略图边框沿用 ease-out，箭头悬停／按下反馈 80ms。
- 真实调用：沿用独立主画布已有的 Terra 结果，追加两次 GPT-6 Luna 短文本请求，形成三份成功输出。真实结果为“第二份文本”及 Markdown 的“第三份文本／这是最新结果”。切换历史不调用 API。
- 手动核对：单份时无历史条；第二份起显示；悬停展开、移出收起、当前项放大、前后箭头、Home／End 与方向键、提示词／结果／模型恢复、TXT／MD 保持、锁定、撤销／重做、刷新恢复。使用 50%、100%、116% 缩放，核对标题拖动、连线跟随、抓手平移和小地图；拖动历史项不移动节点或画布。
- 浏览器模拟：仅拦截本地 `/api/text` 的 Fetch 请求，验证 503 失败及取消均移除待完成项、不追加记录；生成中可查看旧项并返回实时项。拦截已清除，未向真实模型提交这两次模拟请求。
- 减少动态效果：通过临时媒体模拟验证展开没有活动动画，随后已恢复默认媒体设置。连续反向展开／收起后当前项与布局正确。
- 自动测试覆盖历史追加、旧单份结果保留、提示词／模型／格式、序列化恢复及下游读取当前历史输出。完整检查使用 `npm run check`。
