# Text 动效二次对照

2026-11-21，参考用户指定的 FLORA 项目。正式验证使用 `http://localhost:5173/` 的实际主画布，与用户的 `127.0.0.1` 分开存储。

## 实际调用

- FLORA：对既有 Claude Sonnet 5 Text 运行三次，观察等待、流式输出和生成中历史切换；历史由三份增至六份。结束时恢复原来的第三份结果。
- 本地：真实调用一次 GPT-6 Luna，生成 Markdown 短片梗概《The Last Light》。结束时选中此真实结果，截图为 `local-final.jpg`。
- 其余响应、失败、取消和长历史数据均为受控模拟，没有额外提交模型请求。`localhost:5174` 是临时代理下的同一个实际主画布，仅将 `/api/text` 换成每 300ms 一段的 SSE，用于稳定检查持续输出。该临时页面和代理会在验收后关闭。

## 发现并修复

1. 将硬闪烁光标改成 FLORA 的 6 × 14px、2px 圆角呼吸光标：2400ms，透明度 0.7 → 1 → 0.7。
2. 新文字按词以 450ms ease-out 淡入，已读前缀保持不动；中文、Markdown 和代码块保留内容。光标跟随最后一段，末尾为代码块时放在代码块之后。历史读取立即显示，不重新播放文字淡入。
3. 最后增量与完成信号同时到达时，仍保留最终文字的淡入；该边界已用即时完成响应验证。HTML 文本不会执行，代码块原文保持一致。
4. 生成中的历史卡片使用 Image 的填充时间线，完成后显示 T；主卡片保留扫光和约 20 秒的视觉估计，历史填充以 40 秒趋近 95%。估计仅用于参考视觉，不代表服务商实际进度。
5. 查看旧历史时主卡片恢复模型名并停止扫光，待完成缩略图继续运行。返回运行项再取消，会恢复生成前的成功项和提示词；取消不追加历史。
6. 运行期间按钮保持 Image／FLORA 的箭头图标，仍支持停止当前请求。
7. 长历史滚轮原先会被画布缩放抢走；为展开的滚动视口添加 `nowheel`。Text 和 Image 各用十三份结果实测，横向滚动到 110px 时画布变换完全不变。

## 验证范围

- FLORA 实测：等待光标、逐段显现、历史进度、悬停展开／收起、当前卡片尺寸与图标、选择历史时正文即时替换。测量记录见 `reference-motion.json` 和参考 DOM。
- 本地主画布手测：50%／100%／116% 缩放、连续反向悬停、前后箭头、方向键与 Home／End、历史选择、锁定、标题拖动、滚轮边界、撤销／重做和刷新恢复。历史布局投影沿用 250ms，淡入淡出 150ms。
- 持续流式模拟：旧文字透明度保持 1，新文字从低透明度进入；光标位于段尾。手动上滚后输出高度从 350px 增至 551px，滚动位置保持 0，没有被拉到底部。
- 减少动态效果：等待阶段没有活动动画，缩略图显示静态阶段进度；验收后恢复默认媒体设置。
- Image 共用组件：拦截生成请求，核对原有正文填充与扫光；另用十三张图片历史验证滚动与键盘选择。所有拦截均已清除，没有运行真实图片生成。
- 自动检查入口：`npm run check`，日志保存在 `.codex/text-motion-review-check.log`。浏览器测试和真实模型调用不属于自动测试。

关键证据：`local-prefix-stability.json`、`local-fast-completion.json`、`local-view-old-during-run.json`、`local-cancel-restored.json`、`text-history-wheel.json`、`image-history-wheel.json` 和 `local-reduced-motion.json`。
