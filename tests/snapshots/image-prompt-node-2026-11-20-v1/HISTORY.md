# 底部缩略图

2026-11-20 对照同一 Flora 参考节点补齐。仅修改快照组件，不接入真实画布；本轮没有调用模型。

## 默认与悬停

- 节点被选中或悬停时，历史条以 200ms 淡入；离开节点且取消选中后淡出。
- 默认所有缩略图为 32px，第二张起向左重叠 12px；整个轮播透明度 60%。当前项有 1px 描边，其他项以 2px 深色环分隔。左右按钮与序号隐藏。
- 鼠标进入历史区域（包含图片上方的间隙）后展开：各项左边距 2px，当前选中项变成 40px，其他项保持 32px。轮播透明度变为 100%，所有缩略图显示描边，左右按钮与序号出现；不可用的方向按钮透明度 50%。
- 放大的依据是当前选中项，不随鼠标在缩略图之间移动而改变。点击另一张后，放大状态转移到新选中项。
- 移出区域后反向收起；键盘焦点仍在轮播内或存在 `pending` 项时保持展开。序号使用 12px / 13.5px 字体，默认不显示。

展开、收起及选中切换沿用参考的 250ms、`cubic-bezier(.4, 0, .2, 1)`；透明度使用 150ms。先提交最终尺寸，再通过前后布局投影只动画 `transform`，不逐帧动画宽度或间距。中途反向以当前绘制位置为起点；计算会扣除宿主缩放。减少动态效果时直接呈现目标布局，动态开启此设置也会停止正在播放的位移动画。

收起期间临时扩大缩略图视口两侧的裁切范围，动画结束或中断时恢复，沿用参考实现，避免最终窄视口提前裁掉尚在移动的图片边缘。

裁切修复：必须在启动投影动画前读取最终布局的滚动宽度并设置裁切保护。若先启动动画，尚在旧位置的图片会暂时增加 `scrollWidth`，被误判为内容溢出，导致保护分支跳过。现在先收集投影、测量并设置边界，再统一启动动画。复验记录包含三个缩放比例的 36 次边界采样及重录的 74 帧，图片矩形均位于允许显示范围内；结束后恢复默认裁切。新动图见 [history-local-unclipped.gif](evidence/history-local-unclipped.gif)，原 `history-local.gif` 也已替换为修复后的录像。

实现位于 `ImagePromptHistory.tsx` 和 `image-prompt-history.css`，由 `ImagePromptNode` 内部复用，不增加依赖。原来的 `variants`、`activeVariant`、`onVariantChange` 接口继续使用，历史项新增可选 `pending` 布尔值。多项溢出时在内部横向滚动；方向键、Home / End 可切换，当前项会保持在可见区域。

## 点击切换叠化修正（2026-11-20）

再次核对 Flora 实际画面后纠正上一轮结论：主图由 Three.js 画布渲染，DOM 状态和提示词已更新时，画面仍在交叉渐变。此前只检查 DOM 和缩略图动画，把主图误判为立即切换。

本轮录制 43 帧原站画面，以旧图与目标图的像素混合比例拟合，主图约 320ms，接近 ease-in-out cubic（前后慢、中段快）。这与缩略图的 250ms 布局投影是两条独立时间线。提示词、序号与选中状态立即更新；旧主图保留在下层，新主图叠化覆盖，不经过空白或背景色。

新增内部组件 `ImagePromptResult.tsx`：只动画新图层的 opacity，完成后删除旧层；中途点击会冻结现有各层的实际透明度，再从当前混合画面过渡。旧层与新层使用同一组稳定 key，移入旧层列表时不重挂载，避免反向点击跳帧。减少动态效果时直接切换，并清理正在进行的叠化。当前项生成完成仍保留原有 400ms 淡入。

本轮浏览器模拟核对了中间帧双图叠加、140ms 时反向点击前后透明度连续、结束后只保留一层、减少动态效果及动态开启、85% / 100% / 150% 缩放，以及本地生成完成的 400ms 淡入。原站采用实际渲染帧采样，本地同时检查 DOM 状态与画面；不属于主画布验收，没有调用真实模型。
