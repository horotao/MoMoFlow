# Image 节点前端连线

入口：运行 `npm run dev` 后打开 `/tests/snapshots/image-prompt-node-2026-11-20-v1/tests/image-prompt-node.html?connections`。加 `&wired` 初始显示一条连线；`&scale=.5` / `1` / `1.5` 设置初始缩放。页面内也能切换缩放。

左侧是已有组件的完成图片状态，右侧是空白 Image。悬停完成图片，拖动右侧加号到另一节点左侧的 Image 圆环，靠近后自动吸附，松手完成。也可从 Image 输入反向拖到完成图片的输出。Prompt 输入、空白节点输出、自连接、重复连接、环路和锁定节点均不能连接。Image 输入最多展示 16 条图片连接；原型不会将图片或提示词送入模型。

## 参考与视觉

2026-11-20 在用户打开的 Flora 项目实际观察了已有图片连线、自由拖线、兼容图片输入吸附及不兼容 Prompt 输入。Flora 当前使用 WebGL 绘制这些内容，以下线条颜色与吸附参数是视觉对照后的实现值，不是读取到的原始着色器常量。

| 状态 | 实现 |
| --- | --- |
| 自由拖线 | `#eeeeec` 白色，100% 下 2px；约 8px 实段 / 16px 间隔，持续从起拖端流向自由端 |
| 靠近兼容端口 | 保持白色虚线，线头吸到端口圆心；端口浅灰底 `#fafaf223`，不改成绿色或其他类型色 |
| 不兼容端口 | 不吸附、不磁移、不显示错误红色；Prompt 的范围优先排除，避免被相邻 Image 端口抢走命中 |
| 已连接 | `#eeeeec2e` 深灰实线，100% 下 3px；输入圆环显示白色圆心与占用数 |
| 悬停线身 | 线条保持深灰色，两端端口和标签显现；端口继续跟随鼠标轻微磁移，没有额外发光或流动 |
| 选中线身 | 较亮的灰色 `#eeeeec8c`，用于选中与删除反馈；鼠标选中和键盘聚焦均无矩形外框 |

端口继续使用原快照已有的 150ms 显隐与水平展开，以及 160 单位范围内 35% 拉力、最多 20 单位位移、500ms ease-out-cubic 的磁移。有效连接的线头在约 40 节点单位范围内吸附，吸附与脱离过渡为 120ms ease-out-cubic；这些阈值和过渡时间是本原型的视觉匹配值。自由拖线直接跟手，无持续弹簧延迟。线条跟随实际端口位置，包括显隐与磁移动画；线宽、虚线间距和吸附范围随节点缩放。减少动态效果时停止虚线流动，取消吸附插值和端口运动过渡，保留直接拖线反馈。

### 连续帧复核与修正

再次在内置浏览器观察 Flora 后，纠正此前将动态虚线误判为静态的结论。固定指针的连续帧中，虚线向自由端约移动 40 节点单位/秒，24 单位的分段周期约 600ms。曲线中部的实段略长，结合图像采样推断其分段更接近 Bézier 参数间隔，而非 SVG 的等弧长 `stroke-dasharray`。实现用 `wireGeometry.ts` 对 Bézier 子曲线分段并推进相位；以上是渲染画面的测量与拟合，没有读取 Flora 着色器源码。

近垂直拖线去掉此前强制的 48px 最小弯曲宽度，按实际水平距离设置控制点；反向弯折使用 0.25 曲率，并随节点缩放。线条焦点框来自内置浏览器对 SVG `g:focus` 的默认 `outline: auto`：此前只处理了 `:focus-visible`，此次同时处理 `:focus`，键盘焦点仍通过线身亮度反馈。反向吸附输出时，底色限定在圆形图标内，不再填满输出按钮的透明命中区域。

## 组件接口

`components/image-connections/` 是独立 SVG 连线层。宿主管理 `connections: { id, source, target }[]`，通过 `onConnectionsChange` 接收新增或删除；子节点外层声明稳定的 `data-connection-node`，有图片结果的节点声明 `data-has-output="true"`。组件使用 `ImagePromptNode` 的 `data-connection-port` 标识查找端口，不依赖 MoMoFlow 的 React Flow 图数据。

`ImagePromptNode` 新增可选的 `imageInputCount` 和 `outputConnected` 用于展示占用；原有端口点击回调仍保留。`useMagneticPorts` 只在连接层明确标记不兼容时停用该端口磁移；没有连接层的原单节点演示沿用已有表现。锁定节点禁用端口。

拖动通过 RAF 更新 SVG 路径，不在每次 pointermove 时触发 React 状态更新。只有连接提交、删除和节点拖动结束后更新宿主状态；空闲时停止连线帧循环。原生拖动捕获指针以接收画面外松手；Escape、失焦和 pointercancel 清理拖线及临时端口状态。

示例可拖动标题移动节点，线头同步跟随；点击线身选中后 Delete / Backspace 删除，Tab 可聚焦连线、Enter 选中、Escape 取消。左下角提供缩放和清空连线。右侧输入提示词后发送仍是本地演示，约两秒后显示已有图片，不请求模型。

## 验证范围

在独立浏览器存储的快照预览中完成浏览器 DOM / 指针事件模拟：自由虚线、偏离圆心时有效吸附、不兼容 Prompt 的无磁移与无连接、松手成线与占用、反向拖线、重复和自连接拦截、Escape、失焦与指针取消、锁定与解锁、50% / 100% / 150% 缩放及减少动态效果。另通过浏览器原生指针事件核对了实际按下、拖动和松手成线；线身悬停使用浏览器原生 hover 核对端口显现及灰色保持。检查中修正了测试脚本的 select 值和锁定按钮选择器，没有将这些场景错误判为产品回归。

本轮仅实现并验证用户指定的快照前端，没有接入或验收实际主画布、小地图、持久化、生产站点或真实模型调用。截图为原型证据，不作为正式主画布验收截图。

修正复验全部在用户当前的内置浏览器进行，使用原生指针拖拽和键盘操作：复现并修复鼠标选中外框，核对键盘聚焦无框且线身变亮、Delete 删除、正反向拖线与吸附、近垂直拖线、Escape 和松手清理。固定指针下 20 帧、559ms 的预览路径持续变化；减少动态效果时连续采样路径保持一致。另直接运行实际几何模块，核对零水平差无额外 S 弯、相位变化及 600ms 周期、缩放协变和反向相位。
